# Stack Research

**Project:** Góc Nhỏ Tiện Ích Của Ánh
**Feature:** Theo dõi Cân Kho và Container
**Researched:** 2026-07-25

## Recommended Stack Additions

We do not need to add any new npm dependencies. The existing technology stack is fully capable of supporting the new features:
- **Database & Backend:** Supabase (PostgreSQL) is already integrated. We will create a new table `weighbridge_other_tickets` on Supabase.
- **Client Excel library:** `exceljs` is already installed and used in the project for Excel file reading and writing.
- **State Management & UI:** Vue 3 (Composition API) with Tailwind CSS.

## Supabase Database Schema Suggestion

We will create a new table `weighbridge_other_tickets` to store these records:

```sql
create table public.weighbridge_other_tickets (
    id bigint generated by default as identity primary key,
    ticket_no text not null,
    plate_number text not null,
    driver text,
    weight_1 numeric,
    weight_2 numeric,
    weight_net numeric not null,
    date_in timestamp with time zone,
    date_out timestamp with time zone,
    note text,
    type text not null, -- 'warehouse_import', 'container_import', 'container_export'
    container_no text, -- specifically for container shipments
    goods_name text, -- goods type
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    
    constraint weighbridge_other_tickets_ticket_no_type_unique unique (ticket_no, type)
);
```
