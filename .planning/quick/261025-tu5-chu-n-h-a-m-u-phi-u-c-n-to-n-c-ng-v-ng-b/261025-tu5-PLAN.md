# Quick Plan: Chuẩn hóa mẫu phiếu cân toàn cảng và đồng bộ thông tin Nguồn tàu

## Tasks

### Task 1: Database Migration & Service Layer for Master Data & Global Template
- Tạo migration SQL `database/migrations/20261025_add_vessel_master_data_fields.sql` bổ sung cột `customer`, `cargo_type`, `cargo_code` vào `weighbridge_vessels`.
- Trong `WeighbridgeService.ts`:
  - Cập nhật interface `Vessel` với các trường `customer?: string; cargo_type?: string; cargo_code?: string;`.
  - Cung cấp API `getMasterData()`, `saveMasterData(data)` lưu trong `content.settings.weighbridge_master_data` (kèm danh mục mẫu phong phú ban đầu).
  - Cung cấp API `getGlobalTicketTemplate()`, `saveGlobalTicketTemplate(template)` lưu trong `content.settings.weighbridge_standard_template` (kèm fallback IndexedDB / localStorage).
  - Cập nhật `createVessel`, `updateVessel`, `getVessels` để đọc/ghi các trường `customer`, `cargo_type`, `cargo_code` trên Supabase và IndexedDB.
  - Cập nhật hàm nạp cấu hình sà lan để tự động map `owner`, `goods`, `goodsCode` từ Nguồn tàu mẹ.

### Task 2: UI Master Data & Port-Wide Standard Weigh Ticket Designer
- Trong `WeighbridgePrinter.vue`:
  - Thêm nút trên thanh công cụ Báo cáo tổng quan / cân hàng: "Mẫu phiếu cân chuẩn" và "Danh mục Khách hàng & Hàng hóa".
  - Thêm Modal Quản lý Master Data (thêm, sửa, xóa Khách hàng, Loại hàng, Mã hàng).
  - Thêm Modal/View "Cấu hình mẫu phiếu chuẩn toàn cảng" (kéo thả tọa độ, kích thước, font, viền, thông tin doanh nghiệp, người ký), áp dụng chung toàn bộ cảng.
  - Cập nhật modal "Thêm tàu mới" và "Sửa thông tin tàu" để chọn Khách hàng, Loại hàng, Mã hàng từ Master Data.

### Task 3: Lock Inheritance on Barges & Standardize Print Engine
- Trong `WeighbridgePrinter.vue`:
  - Khóa 3 trường Khách hàng, Loại hàng, Mã hàng trên form cấu hình sà lan con (hiển thị badge "Thừa kế từ Nguồn tàu: [Tên tàu]").
  - Thay thế phần kéo thả mẫu in cục bộ ở sà lan bằng thông báo và nút liên kết tới Mẫu chuẩn toàn cảng.
  - Đảm bảo print engine (`#print-section`, `printA5Direct`) luôn render chính xác từ Mẫu chuẩn toàn cảng và dữ liệu thừa kế của Nguồn tàu mẹ.
  - Kiểm tra build `npm test` & `npm run build` đảm bảo không có lỗi type/compile.
