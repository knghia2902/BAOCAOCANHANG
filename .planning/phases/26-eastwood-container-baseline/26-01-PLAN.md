# Phase 26 Plan 01: Khởi tạo Tồn đầu Bãi Container Eastwood (Upload Excel/CSV 1 cột)

## Objective
Cho phép nạp nhanh 2 danh sách container tồn đầu kỳ (`782` cont rỗng + `122` cont đã trả nhà máy = `904` cont, chốt cuối ngày `25/11/2026`) từ file Excel/CSV chỉ cần 1 cột mã container mà **không cần thay đổi schema bảng Supabase** (`eastwood_container_events`), đảm bảo:
- `Trạng thái bãi` và `Sơ đồ kho` phản ánh ngay tồn bãi chính xác và tự động cập nhật khi import phiếu cân từ `26/11/2026` trở đi.
- `Báo cáo ngày (REPORT)` và 3 tab chi tiết chỉ hiển thị phát sinh thực tế từ `26/11/2026` trở đi.

## Tasks

### Task 1: Service — Baseline Container Parser, Builder & Report/Status Separation
**Files:** `src/services/excel/EastwoodContainerService.ts`
**Action:**
1. Add `isBaselineContainerEvent(ev: EastwoodContainerEvent): boolean` checking `ev.id.startsWith('BASELINE_') || ev.soPhieu === 'TON_DAU'`.
2. Add `parseContainerListFromText(text: string): { containers: string[]; duplicateCount: number; ignoredCount: number }` and `EastwoodContainerService.parseContainerListFile(file: File)` (supports `.csv` via `TextDecoder` / UTF-8 and `.xlsx` via `ExcelJS`), scanning all populated cells in the first worksheet, extracting ISO container numbers (`extractContainerNumbers`) + fallback token matching, normalizing uppercase, deduplicating, and returning preview stats.
3. Add `buildBaselineContainerEvents(containers: string[], targetStatus: EastwoodContainerStatus, cutoffDateIso = '2026-11-25'): EastwoodContainerEvent[]`:
   - Maps `EMPTY_YARD` → `flowType: 'LOAD_CONT'`, `RETURNED` → `flowType: 'TRA_CONT'`, `LOADED` → `flowType: 'HA_CONT'`.
   - Sets deterministic ID `BASELINE_${flowType}_${containerNo}`, `soPhieu: 'TON_DAU'`, `actualDate: cutoffDateIso`, `reportDate: cutoffDateIso`, `weighOutTime: '23:59:59'`, `eventDatetime: `${cutoffDateIso}T23:59:59``, `remark: 'Tồn đầu kỳ'`.
4. Update `computeContainerDailyReport(...)` to skip `isBaselineContainerEvent(ev)` so `REPORT` only counts real weighbridge activity (starting 26/11/2026).
5. Update `computeContainerStatuses(...)`:
   - Include baseline events in status calculation.
   - Suppress false `hasWarning` ("Đã Load nhưng chưa có phiếu Hạ Cont") when the container's `latestLoad` is a baseline record (`isBaselineContainerEvent`).
   - Add `isBaselineOnly?: boolean` or clean formatting helper so UI can badge baseline timestamps clearly.
6. Add `EastwoodContainerService.clearBaselineEvents()` to delete only `BASELINE_%` rows from IndexedDB & Supabase (`like('id', 'BASELINE_%')`), preserving all daily weighbridge tickets.

### Task 2: UI — Modal "Nạp tồn đầu kỳ (Excel/CSV)" in `EastwoodContainerManager.vue`
**Files:** `src/components/tools/EastwoodContainerManager.vue`
**Action:**
1. Follow `DESIGN.md` strictly (rounded-`[2rem]` modal, `h-7` compact toolbar buttons, `text-xs` minimum, `primary` `#4a78c2`, puffy primary CTA button).
2. Add toolbar button **"Nạp tồn đầu kỳ"** (`h-7 px-3 bg-teal-600 text-white border border-teal-600 text-xs font-bold rounded-[8px]`) in Card 1 right next to `Import Excel lịch sử` / `Import Phiếu cân`.
3. Build the **"Nạp tồn đầu kỳ Container (Excel/CSV)"** modal:
   - Status selector radio/cards: `Cont rỗng (đang nằm bãi)` (default), `Đã trả nhà máy`, `Cont có hàng`.
   - Cutoff date input (`type="date"`, default `'2026-11-25'`) with helper note: *"Mọi phiếu cân từ ngày 26/11/2026 trở đi sẽ tự động cập nhật trạng thái các cont này."*
   - File drop/select input (`.xlsx, .xls, .csv`) that immediately parses and previews:
     - Total valid unique container numbers found (e.g. `782 cont`)
     - Duplicate count skipped
     - Sample preview chips (first 12 container numbers)
   - Confirm button **"Lưu vào Tồn đầu kỳ"** + secondary action **"Xóa riêng tồn đầu kỳ"** (when baseline events exist).
4. Filter out `isBaselineContainerEvent(e)` from the 3 daily detail tabs (`Hạ Cont`, `Load Cont`, `Trả Cont`) and from the 3 detail sheets in `exportContainerReportExcel` so detail logs stay strictly daily weighbridge operations from 26/11/2026 onward, while `TRẠNG THÁI` and `Sơ đồ kho` display the full 904+ container state!
