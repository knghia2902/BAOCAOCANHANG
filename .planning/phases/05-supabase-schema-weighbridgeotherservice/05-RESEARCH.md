# Phase 5: Supabase Schema & WeighbridgeOtherService - Research

**Phase:** 5
**Domain:** Database Schema & Service Integration
**Date:** 2026-07-27

## Technical Approach

We will create two separate tables on Supabase: `weighbridge_warehouse_tickets` and `weighbridge_container_tickets`.

### 1. Supabase Database Schema

```sql
-- Table for Warehouse Weighing Tickets
create table public.weighbridge_warehouse_tickets (
    id bigint generated by default as identity primary key,
    ticket_no text not null,
    plate_number text not null,
    driver text,
    weight_1 numeric,
    weight_2 numeric,
    weight_net numeric not null,
    date_in timestamp with time zone,
    date_out timestamp with time zone,
    goods_name text,
    note text,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    
    constraint weighbridge_warehouse_tickets_ticket_no_unique unique (ticket_no)
);

-- Table for Container Weighing Tickets
create table public.weighbridge_container_tickets (
    id bigint generated by default as identity primary key,
    ticket_no text not null,
    plate_number text not null,
    driver text,
    weight_1 numeric,
    weight_2 numeric,
    weight_net numeric not null,
    date_in timestamp with time zone,
    date_out timestamp with time zone,
    container_no text,
    goods_name text,
    note text,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null,
    
    constraint weighbridge_container_tickets_ticket_no_unique unique (ticket_no)
);
```

Enable Row Level Security (RLS) and create appropriate policies if needed.

### 2. Service Layer implementation (`WeighbridgeOtherService.ts`)

Create a new file `src/services/excel/WeighbridgeOtherService.ts` containing:
- Interfaces `WarehouseTicket` and `ContainerTicket`.
- Methods:
  - `getWarehouseTickets()`: Fetch records from Supabase table.
  - `getContainerTickets()`: Fetch records from Supabase table.
  - `saveWarehouseTickets(tickets: WarehouseTicket[])`: Upsert records in chunks.
  - `saveContainerTickets(tickets: ContainerTicket[])`: Upsert records in chunks.
  - `deleteWarehouseTicket(id: number)` & `deleteContainerTicket(id: number)`.
  - `clearAllWarehouseTickets()` & `clearAllContainerTickets()`.
- Excel parsing:
  - Read files using `exceljs`.
  - Column matching (auto-detect headers like "Số phiếu", "Biển số", etc.).
  - Trích xuất thêm cột `goods_name` (kho) và `container_no` (container).
