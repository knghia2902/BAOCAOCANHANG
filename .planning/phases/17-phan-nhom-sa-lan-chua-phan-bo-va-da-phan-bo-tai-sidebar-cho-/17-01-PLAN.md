<title>Khai báo reactive state và computed phân loại sà lan Chưa phân bổ vs Đã phân bổ</title>
<action>
Trong `src/components/tools/SingleBargeAllocator.vue`:
1. Thêm reactive state tab trạng thái sà lan tại sidebar:
   ```typescript
   const selectedBargeStatusTab = ref<'pending' | 'completed'>('pending');
   ```
2. Thêm hàm helper kiểm tra một sà lan đã được phân bổ hay chưa dựa trên `existingTrips` (dữ liệu trong Sổ theo dõi / `weighbridge_allocation_tracking`):
   ```typescript
   function isBargeAllocated(barge: { id: number; name: string; config?: any }): boolean {
       return existingTrips.value.some(t => 
           (t.bargeId && Number(t.bargeId) === Number(barge.id)) ||
           (barge.name && t.bargeName === barge.name) ||
           (barge.config?.orderNo && t.orderNo === barge.config.orderNo)
       );
   }
   ```
3. Thêm hàm lấy thông tin tóm tắt phân bổ của sà lan (số chuyến, tổng tấn):
   ```typescript
   function getBargeAllocatedSummary(barge: { id: number; name: string; config?: any }) {
       const trips = existingTrips.value.filter(t => 
           (t.bargeId && Number(t.bargeId) === Number(barge.id)) ||
           (barge.name && t.bargeName === barge.name) ||
           (barge.config?.orderNo && t.orderNo === barge.config.orderNo)
       );
       const totalWeightKg = trips.reduce((sum, t) => sum + (t.weightNet || (t.weightTons * 1000) || 0), 0);
       return {
           tripCount: trips.length,
           totalTons: totalWeightKg / 1000
       };
   }
   ```
4. Thêm computed `allDeHeusBarges`, `unallocatedBarges`, `allocatedBarges`:
   - `allDeHeusBarges`: Tập hợp toàn bộ sà lan từ `sourceVessels.value`.
   - `unallocatedBarges`: Các sà lan có `!isBargeAllocated(b)`.
   - `allocatedBarges`: Các sà lan có `isBargeAllocated(b)`.
</action>
</task>
